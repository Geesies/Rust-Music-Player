artists/album tab:
this will function by first showing all artists verticaly listed alphabetically. with special charactors and non english text being first.


dynamic window tab:
this window will work by dynamically showing data based on what is selected. if nothing is selected it will just show all artists as thumbnails witht he name of the artist below that thumbnail.
if an artists is selected it will show all albums by that artist as thumbnails with the name of the album below that thumbnail.

the bottom bar is built in the following order:
play, pause, previous, next, shuffle toggle, scrub bar, volume.

the dynamic album art tab will force the song/album art for whatever is playing. if nothing is playing it will show the artist, album, song that is selected.
